# Synchronisation Obligatoire de la Documentation

À chaque modification de code (frontend, backend, base de données, API, UI) :
- Mettre à jour systématiquement le document `Documentation_Technique_E-Schola_Pro.html`.
- Mettre à jour les modèles, routes, options de module ou captures d'écran selon la nature du changement.
- S'assurer que le document reste toujours complet, à jour et exportable en PDF sans erreur.
